## New Features

- **[UI/UX]**: Updated global UI text scaling by tweaking `--font-size-body` and `--leading` variables for more consistent rendering across controls and prose.
- **[UI/UX]**: Added collapsible "Recent" history section to the sidebar, with its state persisted locally in `localStorage`.
- **[UI/UX]**: Added parameter help popovers (`?` icon) with descriptions and min/max/default value metrics, rendering natively using fixed positioning to escape clipping.
- **[UI/UX]**: Cleaned up the chat history item design, removing icons and streamlining the layout to allow more density.
- **[Cloud Support]**: Added detection logic for cloud-hosted Ollama models (`views.py`). When detected, local runtime execution parameters (e.g., GPU layers, memory limits) are now hidden in the parameters UI (`parameters-ui.js`).
- **[Locales]**: Added new string translations for the "Recent" sidebar label across all 20 supported languages.
- **[Documentation]**: Added generated documentation for internal helper methods in `views.py` (`_ollama_model_is_cloud`), `event-bindings.js` (collapse map state reading/writing, help popover positioning), and `parameters-ui.js` (popover HTML building and styling logic).
