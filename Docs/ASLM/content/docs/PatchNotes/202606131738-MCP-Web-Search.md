## New Features

- **[Web Search Tool]**: Introduced the primary `web_search` tool to the MCP server. It runs queries across multiple engines (Google, Brave, DuckDuckGo, Yandex, Qwant, Yep, and Startpage) in parallel, deduplicates results by cross-engine consensus, ranks the pool, and optionally parses the best pages into markdown based on a configurable `effort` level ('low', 'medium', 'high').
- **[Search IO Logger]**: Added `search_io_logger.py` to log search tool inputs and outputs. It records full search and read_page tool IO events to a readable JSON array (`logs/model_search_io.json`) to allow post-facto inspection of exact requests and responses.
- **[Logging]**: Expanded `logging_setup.py` to wire rotating file logs for `services.web_search`, `trace.web_search`, and `mcp.server`, ensuring logs are captured and backward-compatible.
- **[Documentation]**: Added new reference pages for `logging_setup.py`, `web_search.py`, and `search_io_logger.py`. Updated the `mcp-server.md` documentation to reflect the new `call_tool` routing and `_call_web_search` implementation.

## API Changes

- **[MCP Server]**: The primary search tool is now `web_search`, introducing the `effort` parameter (options: `low`, `medium`, `high`) while defaulting to `medium`. The existing raw SERP tool has been retained as `serp_search` (raw) for low-level unprocessed engine outputs.
