## New Features

- **[MCP Server]**: Implemented `_evict_caches_once` in `mcp-server.py` to reclaim disk from expired cache entries once per process on the first tool call.
- **[Documentation]**: Added documentation for `_evict_caches_once()` in `mcp-server.md`.
