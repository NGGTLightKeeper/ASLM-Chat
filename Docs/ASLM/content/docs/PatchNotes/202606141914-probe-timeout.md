## New Features

- **[Search Core]**: Added a `PROBE_TIMEOUT` of 60 seconds to `EngineHealthTracker` to prevent engines from being permanently wedged shut if a half-open probe's outcome is lost (e.g., cancelled by search deadline before the engine status event is consumed). Abandoned in-flight probes will now be gracefully expired.
- **[Documentation]**: Added module documentation for the `core/search` package, including `health`, `prefetch`, and core tests.

## Bug Fixes

- **[Prefetch]**: Improved URL list order-preserving deduplication in `PrefetchManager.schedule`.

## API Changes

- **[Internal API]**: Added `probe_started` timestamp field to `EngineHealth` dataclass for tracking half-open probe lifetimes.
