## New Features

- **[UI]**: Updated the settings sidebar collapse functionality. The collapse button is now a fixed, floating toggle at the top right of the screen.
- **[UI]**: Added pre-paint state restoration logic via `localStorage` to prevent sidebar animation flashes on load when settings are collapsed.
- **[UI]**: Refactored the chat message layout (`.msg`) from flexbox to a CSS grid layout for better alignment of avatars and message bodies.
