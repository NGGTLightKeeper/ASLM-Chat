## New Features

- **[MCP Web Search]**: Implemented a new `web_search` MCP server (`Tools/mcp-web-search/mcp-server.py`) exposing the `serp_search` tool for parallel raw SERP retrieval from Google, Brave, and DuckDuckGo.
- **[MCP Web Search Core]**: Added complete search engine integrations under `Tools/mcp-web-search/core/engines/`:
  - `brave.py`: Brave Search SERP parser with support for time limits and safe search.
  - `duckduckgo.py`: DuckDuckGo HTML SERP parser.
  - `google.py`: Google SERP parser with structural fallbacks.
  - `models.py`: Immutable models (`EngineRequest`, `SearchResult`, `EngineParseResult`) for describing HTTP requests, single results, and engine responses.
  - `parsing.py`: Utilities for parsing HTML via `LexborHTMLParser` and extracting search results safely.
- **[MCP Web Search Transport]**: Added `Tools/mcp-web-search/core/fetch/` modules:
  - `transport.py`: Includes `AdaptiveTransport` that routes each engine to optimal backends: fast `aiohttp` for DuckDuckGo, `primp` for Brave, and `httpx` for Google.
  - `httpx_transport.py`: Uses legacy GSA mobile user-agents with per-request TLS fingerprint randomization to safely bypass anti-bot mechanisms.
  - `profiles.py`: Generates randomized browser identities to spoof requests effectively.
- **[MCP Web Search API]**: Introduced `SerpApi` in `Tools/mcp-web-search/core/search/serp_api.py` for concurrent execution of engines and streaming serialized result payloads.
- **[Documentation]**: Added generated documentation pages for all new components under `Docs/ASLM/content/docs/ASLM-Chat/Tools/mcp-web-search/`.
