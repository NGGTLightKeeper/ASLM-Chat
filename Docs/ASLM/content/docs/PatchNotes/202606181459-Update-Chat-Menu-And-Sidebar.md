- **[UI/UX]**: Updated the Chat Menu and Sidebar. Integrated MCP (Model Context Protocol) server settings directly into the "Other" composer menu as a flyout entry, mirroring the skills UI behavior. Added a dedicated `mcp.svg` icon for MCP tools.
- **[Localization]**: Added `"noServers"` string and respective translations across all 20 supported locale files to handle the empty state of MCP servers.
- **[Documentation]**: Updated documentation corresponding to the chat menu and sidebar modifications.
